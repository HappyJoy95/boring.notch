# DSH 灵动岛插件 0.3.0

通过 DSH 的公开 `sessionController` 与 `workspaceController` 接口，将置顶会话接入灵动岛。支持读取状态、查看历史、发送文字消息和打断当前一轮运行，不读取 DSH 会话日志，也不模拟点击。

## 安装与更新

1. 从灵动岛「设置 → AI Agent → DSH 插件」在访达中显示内置 0.3.0 安装包。
2. 解压后，在 DSH 的插件管理器添加插件文件夹。更新时停用旧版，避免同时运行两个桥接插件。
3. 启用新插件并重启 DSH；灵动岛也需运行包含发送和打断接口的新版本。
4. 在 DSH 置顶会话，打开灵动岛的对应会话窗口。空闲时发送文字；运行时点击停止按钮打断当前一轮。

## 控制行为

- 发送调用 `sessionController.prompt({ sessionId, requestId, mode: 'queue', content })`。成功仅表示 DSH 接受消息，不表示任务完成。
- 打断调用 `sessionController.cancel({ sessionId })`，保留 DSH 待处理队列，不修改审批或权限。
- 每次操作核对最新置顶集合，只允许非空、非子代理会话。取消置顶后不能继续发送或打断。
- 本地桥接绑定 127.0.0.1，使用随机令牌，拒绝浏览器 Origin 请求。令牌文件为当前用户专用权限。
- 消息最多 8192 UTF-8 字节；同一请求标识的重复提交不会再次执行。收不到回执时不自动重发，请先在 DSH 核对。
- 老版插件或缺少公开控制接口的 DSH 会返回不可用提示，不会回退到修改日志或模拟点击。

`package.sh` 生成可在其他安装了 DSH 的 Mac 上使用的安装包。插件令牌在目标电脑生成，安装包不包含本机配置或凭据。
