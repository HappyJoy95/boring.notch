# QQ 音乐与网易云歌词

按当前播放器优先取对应来源的歌词：Apple Music 可用时先读播放器自身的歌词；QQ 音乐和网易云优先各自曲库；其他播放器优先通用来源。对应来源没有可信匹配或接口失败时才回退 LRCLIB。

QQ 音乐 macOS 没有通过系统播放信息公开歌词或歌曲目录 ID，灵动岛无法直接读取其内部歌词对象；QQ 来源因此用当前播放的曲名、歌手、专辑和时长在 QQ 曲库匹配，再取对应歌词。匹配优先要求歌手、标题/版本和时长一致，并用专辑消歧；无可信匹配时才回退通用源。采用匿名请求，不读取播放器账号、Cookie 或本地数据库。

QQ 音乐按“歌名 + 歌手”请求搜索，并进一步核对歌手、标题/版本、时长及专辑，避免同名翻唱误用原唱歌词。保留标题带版本后缀的候选；遇到本地曲名与曲库别名不同时，仅在专辑和时长都强匹配时接受。网易云与 LRCLIB 也核对歌名和歌手，已知双方时长差超过 3 秒则排除；专辑一致的候选优先。成功结果保留最多 128 条内存缓存。换歌或切换来源时取消旧任务，并通过请求标识拦截旧结果。

LRC 支持 1 至 3 位小数、重复时间标签、offset 和空白间奏。第一句时间之前不提前显示歌词。折叠歌词区区分加载中、无歌词与无逐句歌词，不把整首纯文本塞成一行。

## 验证

在项目目录执行：

```sh
swiftc -parse-as-library boringNotch/services/LyricsService.swift Tests/Lyrics/main.swift -o /tmp/boring-lyrics-tests
/tmp/boring-lyrics-tests
```

添加 `--live` 可进行平台匿名联网验证，包括 QQ《화 (火花)》的版本标题结果。正常离线测试涵盖选源、歌曲版本、歌手别名、时间解析、接口异常回退、缓存和已取消任务。

2026-10-04 验证：QQ《晴天》、网易云《起风了》均返回平台同步歌词，Debug 构建通过。播放器 UI 中切歌、暂停、跳转进度仍需运行新版验证。

## 接口依据与限制

- [QQ 接口实现参考](https://github.com/Yyyangshenghao/simple-music/blob/master/server/lib/qq-client.ts)
- [网易云搜索与歌词接口参考](https://github.com/u3u/NeteaseCloudMusicApi)
- [LRCLIB 文档](https://lrclib.net/docs)

平台接口并非承诺兼容的桌面歌词接口，后续改版可能失效。歌曲信息缺失或版本不一致时宁可显示无歌词，不强行采用搜索第一条。逐字高亮和翻译歌词暂未实现。
